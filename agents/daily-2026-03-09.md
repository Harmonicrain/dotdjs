## Issues Found

### 1. DUPLICATED: Player damage/downed logic copy-pasted across 3 files
**Severity**: Medium — maintenance hazard, divergence risk
**Files**:
- `systems/zombie/ZombieDamageSystem.ts` (lines 45-80 in `handlePlayerDamage` AND lines 143-166 in the `update` loop)
- `systems/ProjectileSystem.ts` (lines 80-110 in `handleExplosion`)

The exact same "check health <= 0, check solo/quickRevive, set downed state, send PLAYER_DOWNED message" block is copy-pasted **3 times**. Even within `ZombieDamageSystem.ts` alone, the `handlePlayerDamage` event handler (line 45) duplicates the inline damage code in the `update` loop (line 143). If downed logic ever changes (e.g., new perk interactions), 3 places need updating.

### 2. DUPLICATED: `getHorizontalDist` defined independently in 2 files
**Severity**: Low — simple utility duplication
**Files**:
- `systems/zombie/ZombieAISystem.ts` (lines 107-120, two versions: `getHorizontalDist` and `getHorizontalDistSq`)
- `systems/zombie/ZombieDamageSystem.ts` (line 41, using `Math.pow` instead of `dx*dx` — also slightly less performant)

The ZombieDamageSystem version uses `Math.pow(x, 2)` which is slower than `dx * dx`. Both should share a single utility from `engine/`.

### 3. DEAD CODE: `_tempGravity` scratch vector allocated but never used
**Severity**: Low — dead allocation
**File**: `systems/zombie/ZombieAISystem.ts` (line 46)

```ts
const _tempGravity = new BABYLON.Vector3();
```

This pre-allocated scratch vector is never referenced anywhere in the file. Gravity is applied directly via `_tempMoveResult.y += gc.GRAVITY * 3 * frameFactor` throughout. Remove it.

### 4. PER-FRAME ALLOCATION: `new BABYLON.Vector3` inside `performKnife` hot path
**Severity**: Medium — violates AGENTS.md rule about no `new` in update functions
**File**: `systems/player/PlayerCombatSystem.ts` (line 279)

```ts
knife.position = new BABYLON.Vector3(0.2, -0.2, 0.5);
knife.rotation = new BABYLON.Vector3(0, Math.PI / 2, 0);
```

Every knife press allocates 2 Vector3s. Should use `knife.position.set(0.2, -0.2, 0.5)` and `knife.rotation.set(0, Math.PI / 2, 0)` instead.

### 5. PER-FRAME ALLOCATIONS: `new BABYLON.Vector3` in MysteryBoxSystem state handlers
**Severity**: Low-Medium — allocations in render-adjacent code
**File**: `systems/MysteryBoxSystem.ts` (lines 81, 167, 185, 229, 239)

Multiple `new BABYLON.Vector3(scale, scale, scale)` allocations inside state handler functions that run every frame. Should use `scaling.set(x, y, z)` or `scaling.copyFromFloats(x, y, z)` instead.

### 6. `any` TYPE VIOLATIONS: Multiple uses of `any` in systems
**Severity**: Low — violates strict typing rule in AGENTS.md
**Files**:
- `systems/NetworkSystem.ts` line 39: `const _zombiesSnapshot: any[] = []`
- `systems/ProjectileSystem.ts` line 34: `setDebugInfo(v: any): void` and line 161: `handleRemoteShoot = (msg: any)`
- `systems/ZoneSystem.ts` lines 36, 61: `zone.bounds as any`
- `systems/zombie/ZombieAISystem.ts` line 346: `let windowMapSnapshot: any = null`
- `systems/zombie/ZombieAnimationSystem.ts` lines 100, 115: `z.mesh as any`

These should have proper typed interfaces.

### 7. DUPLICATED: PowerUpSystem spawns power-ups with `camera.getDirection` + `.add()` per-frame allocation
**Severity**: Low — only triggers on threshold crossing, not every frame
**File**: `systems/PowerUpSystem.ts` (lines 74-78)

```ts

forward.y = 0;
forward.normalize();

- systems/zombie/ZombieAISystem.ts (lines 107-120) — uses dx*dx
- systems/zombie/ZombieDamageSystem.ts (line 41) — uses Math.pow(x, 2) which is slower

YOUR TASK:
1. Add these two functions to engine/GeometryUtils.ts (it already exists):
   ```ts
   export const getHorizontalDist = (p1: BABYLON.Vector3, p2: BABYLON.Vector3): number => {
       const dx = p1.x - p2.x;
       const dz = p1.z - p2.z;
       return Math.sqrt(dx * dx + dz * dz);
   };

   export const getHorizontalDistSq = (p1: BABYLON.Vector3, p2: BABYLON.Vector3): number => {
       const dx = p1.x - p2.x;
       const dz = p1.z - p2.z;
       return dx * dx + dz * dz;
   };
   ```
2. Import and use them in ZombieAISystem.ts — remove the local definitions (lines 107-120)
3. Import and use in ZombieDamageSystem.ts — remove the local definition (line 41)
4. Run `npm run build` to verify no errors
